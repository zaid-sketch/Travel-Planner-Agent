# AI-Powered Travel Planner Agent

## Project Overview
An AI-powered Travel Planner Agent built to assist users in planning trips efficiently and intelligently[cite: 7]. The system uses real-time data and IBM generative AI models to suggest destinations, build personalized itineraries, and recommend transport and accommodation options tailored to individual user preferences, budgets, and constraints[cite: 7].

## Domain
Travel / Tourism / Agentic AI[cite: 4, 7]

## Technology Stack & IBM Tools Used
* **IBM Cloud Lite Services / watsonx.ai**: For scalable model deployment and AI governance[cite: 2, 7].
* **IBM Granite Models (`granite-4-h-small`)**: For natural language understanding, reasoning, and itinerary generation[cite: 4, 7].
* **Langflow**: For designing and orchestrating multi-agent workflows visually[cite: 4, 7].
* **Retrieval-Augmented Generation (RAG)**: For fetching and summarizing local guides, weather updates, and travel policies from trusted sources[cite: 7].
