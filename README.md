# AI-Powered Travel Planner Agent

## Project Overview
An AI-powered Travel Planner Agent built to assist users in planning trips efficiently and intelligently. The system uses real-time data and IBM generative AI models to suggest destinations, build personalized itineraries, and recommend transport and accommodation options tailored to individual user preferences, budgets, and constraints.

## Domain
Travel / Tourism / Agentic AI

## Technology Stack & IBM Tools Used
* **IBM Cloud Lite Services / watsonx.ai**: For scalable model deployment and AI governance.
* **IBM Granite Models (`granite-4-h-small`)**: For natural language understanding, reasoning, and itinerary generation.
* **Langflow**: For designing and orchestrating multi-agent workflows visually.
* **Retrieval-Augmented Generation (RAG)**: For fetching and summarizing local guides, weather updates, and travel policies from trusted sources.

## Features
* **Personalized Itineraries**: Tailors travel plans based on user budget, destination, and schedule constraints.
* **Real-Time Integration**: Connects with maps, weather updates, and local guides for seamless trip management.
* **Multi-Agent Architecture**: Coordinates specialized tasks like destination selection, local expert consulting, and concierge planning.
